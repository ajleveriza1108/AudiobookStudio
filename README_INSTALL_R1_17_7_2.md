# Install Audiobook Studio R1.17.7.2

1. Close Audiobook Studio.
2. Extract the complete ZIP.
3. Double-click `INSTALL_R1_17_7_2_COMPLETE_FIX.bat`.

Default project: `D:\Python\AudiobookStudio`

The installer backs up changed source, verifies the complete regression suite,
quarantines only stale OCR caches, preserves `.venv` and `.gpu-venv`, and rolls
back automatically if a gate fails.
